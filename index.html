WHAT'S INSIDE

一个人用 AI 写的太空游戏，做满了该有的细节

没有用任何外部美术素材：银河、飞船、音效、星空，全部是代码生成的。

01

程序化银河

4096×2048 等距柱状投影，5 万+ 颗星、倾斜银河带、尘埃暗巷、紫青星云斑块，左右无缝环绕，纯 numpy 生成。

02

三种视角

追尾视角、第一人称、驾驶舱内景。舱内有控制台、反应堆、绿植和床铺，透过舷窗看外面的星河。

03

猎兵级歼星舰

Boss 是一艘 8 段收窄船体的母舰，配三座会瞄准你的炮塔，加钛战机与拦截机编队。

04

20 个合成音效

激光、爆炸、警报、护盾、充能……连同背景音乐，全部由 Python 的波形函数现场合成，零版权风险。

05

生存系统

HP、能量、口渴、饥饿、等级、护盾、导弹、炸弹、悬停充能。打不动了就停下来充电，再冲上去。

06

六个结局

降落、黑洞、被击落、击毁母舰……每个结局都有独立的过场字幕和结算面板，结局收集在主菜单里。

CONTROLS

操作

键盘 + 鼠标。W 加 Shift 是双倍加速，耗电也是双倍。

按键作用
W / S前进 / 倒退（消耗能量）
A / D左右偏航
↑ / ↓抬头 / 低头
W + Shift双倍加速（耗电也双倍）
鼠标左键开火（每发 5 能量）
1 / 2 / 3单发 / 三连散射 / 高速连射
空格冲刺（带无敌帧）；片头中 = 跳过片头
J悬停充能（必须停下）
Q / E / F治疗 / 喝水 / 进食
R护盾（4 秒）；结算画面 = 重开
P切换视角：追尾 / 第一人称 / 驾驶舱
4 / 5导弹 / 炸弹
K降落星球
O星云附近 = 进入黑洞；其他位置 = 暂停
M / F2 / ESC静音 / 显示隐藏提示 / 退出
REQUIREMENTS & FAQ

下载之前

运行要求

  • 系统Windows 10 / 11 64 位
  • 显卡支持 OpenGL（集显也可以）
  • 磁盘约 280 MB（解压后）
  • 分辨率建议 1280×720 以上
  • 网络下载时需要，玩的时候不需要
  • 安装不需要，解压即玩
为什么不能直接在网页里玩？+
这个游戏是用 Ursina + Panda3D 的桌面引擎写的，浏览器没有对应的 WebGL 运行时，所以只能下载到 Windows 上跑。要做纯网页版得换成 Three.js 重写一遍，那是另一个项目。
解压后打不开怎么办？+
先双击「启动游戏-调试.bat」，它会保留命令行窗口并把具体报错显示出来。多数情况是显卡驱动太旧，更新驱动即可。
会被杀毒软件拦吗？+
包里是 Python 官方解释器 + 开源引擎，没有加壳。个别杀软对 .bat 启动器敏感，可以放行，或直接用调试版启动器。
可以转发给别人吗？+
可以，直接把这个下载页的链接发出去就行。游戏本体免费。
